# Jakariya Ahmed — Website Hub

A responsive single-page website that collects my GitHub Pages projects in one place.

## Publish with GitHub Pages

1. Create a new public repository.
2. Upload `index.html`, `style.css`, `script.js`, `robots.txt`, and `sitemap.xml`.
3. Enable GitHub Pages from Settings → Pages.
4. After the site is live, replace `YOUR-REPOSITORY-NAME` in `robots.txt` and `sitemap.xml` with the actual repository name.
5. Submit the sitemap URL in Google Search Console.
